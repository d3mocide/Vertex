// 00 · ATLAS BRIEF

Ten categories,
six states,
one 256×256 sheet.

The Atlas is the icon system that sits on the map — every entity, sensor, and incident in Vertex renders from a single 256×256 sprite sheet. Categories have distinct silhouettes where shape matters; tracked vehicles (aircraft and vessel) share a CoT-style chevron and are differentiated by heading rotation and category color. Color carries severity; halo, ring, and dot are reusable utility slots stamped on top.

// SHEET CONTRACT atlasIcons.ts

Every sprite is authored monochrome white at 64 × 64, drawn into a single offscreen canvas, and consumed by deck.gl IconLayer in mask=true mode.

Categories with hard voids — mesh, fire, camera — punch transparency via destination-out so the basemap shows through.

The icon's pixel color comes from getIconColor per feature; the sprite contributes alpha only.

// 05 · ANATOMY

Construction

32×32 GRID · 1PX UNITS
4PX SAFE AREA
1U = 1PX · 32U FRAME
// 32 × 32 GRID
Every mark is authored on the same grid as the Scope logo. Coordinates align to whole pixels — x,y ∈ ℤ. No half-pixel anchors.
// 4PX SAFE AREA
All glyph geometry stays inside the inner 24 × 24 region. The outer 4px ring reserves space for the selection bracket and active halo without redraw.
// HEADING PIVOT
Directional categories (air, sea) rotate around (16, 20) — the vehicle's geometric centroid, not the canvas center, so heading rotation looks correct.
// FILL VS STROKE
FULL bucket uses solid fills. SIMPLIFIED uses 1.6px strokes at 32U scale. RING and DOT share the same primitive across all categories.
// HALO
Halo radius is 2× icon radius, centered on the pivot. Color = current category hue for ACTIVE, swap to --cat-emerg for CRITICAL.
