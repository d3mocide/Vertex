The mark is a viewfinder closing on a vertex: four corner brackets frame an inner diamond — the apex — locked by a single amber pip. It collapses three earlier finalists (Bracket Reticle, Waypoint Node, V Monogram) into one: tactical framing, navigational geometry, and the literal vertex of a plotted target. Every element is on the 32×32 grid; nothing rounds.

CONSTRUCTION & CLEARSPACE X = PIP UNIT · 4PX
1X = 4PX
// CLEARSPACE
Maintain 1X minimum clearance on every side. Inside the dashed boundary the mark is sovereign — no type, no UI chrome, no cropping.
// GRID
All vertices snap to the 32 × 32 integer grid. Bracket arms are 6X long × 1X stroke. Diamond vertices at (16,7)·(25,16)·(16,25)·(7,16).
// PIP
The amber pip is 4 × 4 centered at the optical vertex. It is the only filled shape and the only use of --amber-gold in the mark.
// DON'T
Don't recolor the pip · don't round corners · don't add a background plate · don't outline the wordmark · don't combine with the legacy V monogram.

// 11 · PATTERNS

Principles & Do/Don't

OPS-ROOM ETHOS
DENSITY ≠ NOISE

// COLOR IS A SIGNAL

Amber-gold is reserved for primary action and live data. Cyan, green, orange, red are semantic — never aesthetic. If a color appears, it means something specific.

// SHARP & FLAT

Zero corner radius across the system. Rounded only for status dots and map markers. Avoid drop shadows except for amber/red glow on live or critical elements.

// MONO FOR DATA

Roboto Mono for all numeric values, timestamps, callsigns, coordinates. Inter for prose, labels, and headings. Tabular alignment in data rows.

// TIGHT TRACKING

Caps labels track at +18%. Display headings track at -2%. Body copy is neutral. Density is achieved through small type and tight gaps, not by removing whitespace.

// LAYER OVER MAP

Map canvas is desaturated to 0% with brightness 0.6 and contrast 1.3. All HUD chrome floats above with backdrop blur. The map is context, the panels are content.

// CALM → CRITICAL

The CRITICAL mode tints the header red, switches priority elements to red-emergency, and amplifies pulse motion. The system has two emotional states — never more.

check_circle DO
  • Use mono for every number, callsign, timestamp, coordinate.
  • Reserve amber-gold for primary action and live signal.
  • Keep panels glassmorphic over map; opaque over solid surfaces.
  • Use 1px borders in amber-gold-muted for panel edges.
cancel DON'T
  • Don't introduce rounded corners or soft shadows.
  • Don't use signal colors decoratively — they have meaning.
  • Don't use Inter for numeric data tables; lose tabular alignment.
  • Don't over-animate — motion is for liveness and alerts only.
